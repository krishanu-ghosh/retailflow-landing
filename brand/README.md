# RetailFlow logo

Three bill slips, for **sale** (bag), **stock** (carton) and **rupee** (₹), joined by one running stitch: every part of the shop, bound into one app.

## Files

| File | Use |
|---|---|
| `lockups/retailflow-horizontal.svg` | Default logo: site header, documents, email signatures |
| `lockups/retailflow-stacked.svg` | Square-ish spaces: splash screens, social posts, packaging |
| `lockups/retailflow-wordmark.svg` | Where the symbol is already shown nearby, or space is very wide and short |
| `symbol/retailflow-symbol.svg` | Symbol alone, 48 px and up |
| `symbol/retailflow-symbol-small.svg` | Symbol below 48 px: no icons, no needle, heavier stitch |
| `web/` | favicon.ico/svg, apple-touch-icon, PWA icons, `site.webmanifest`, `head-snippet.html` |
| `png/` | Raster copies for tools that can't take SVG |

The wordmark is General Sans Semibold (Indian Type Foundry, Fontshare free licence), converted to outlines. No font is needed to display the logo.

## Colour

| Role | Hex |
|---|---|
| Sale slip (turmeric) | `#D18A1C` |
| Stock slip (indigo) | `#33467E` |
| Rupee slip and "Flow" (brick) | `#BB3D31` |
| Thread and "Retail" (ink) | `#1D1614` |
| Paper edges and icons (cotton) | `#F8F4F1` |
| Page curl | `#F0B7A6` |

Use the logo on light, warm backgrounds (cotton, paper, white). The thread and the word "Retail" are ink, so they disappear on dark backgrounds.

## Size and space

- Clear space on every side: at least the width of one slip's icon (about the height of the "R" × 0.4).
- Horizontal lockup: minimum 120 px wide on screen, 30 mm in print.
- Symbol: use `retailflow-symbol-small.svg` below 48 px.

## Don't

- Recolour, reorder or remove slips.
- Restyle the stitch (solid line, different dash) or drop the thread.
- Stretch, rotate, outline, or add shadows or gradients.
- Retype "RetailFlow" in another font. Use the outlined files.
- Place it on busy photos or dark backgrounds.
