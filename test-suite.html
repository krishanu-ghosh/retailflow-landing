RetailFlow — Tenant Portal Manual Test Guide

A step-by-step checklist for testing the shop-owner / staff side of the app by hand. No technical knowledge required — just follow each step and mark what happened.

Before you begin

  • Use a test / staging business, not one real customers actually use. Several steps below create test sales, customers, expenses etc. on purpose.
  • You'll need login details for at least an Owner account. Tests marked Manager or Cashier need those accounts too — ask your team for them if you don't have them. If you only have an Owner login, you can skip role-specific tests (mark them N/A).
  • Each test has: what data to type in (if any), the exact steps to click through, and what you should see if everything is working. Tick Pass if it matches, Fail if it doesn't (write what happened in the notes box), or N/A if you can't run it (e.g. no Cashier login available).
  • Your answers are saved automatically in this browser as you go — closing the tab or restarting your computer will not lose your progress. Use Reset All Test Data (bottom of the page) only when you want to start completely over.
  • When you're done (or want to hand off progress), click Download Results at the bottom to save a text file summary you can send to your team.
  • Prefer a guided, one-at-a-time flow? Click 🎯 Focus Mode (top of the page) to step through tests one by one, or the small 🎯 Focus this section button on any section header to walk through just that section. While it's open you can use 1/2/3 to mark Pass/Fail/N-A, ←/→ to move between tests, C to copy the sample data, and Esc to exit. ⏭ Next untested and 🎲 Random test jump you straight to a test without scrolling.
